# Athena's Children: A Yale Computing History

A love letter to Yale's computing infrastructure naming conventions from the 90s/2000s.

## About

This single-page website documents the naming conventions used for Yale's computing infrastructure during the 90s and 2000s. Inspired by MIT's Project Athena, Yale's systems administrators created a rich tapestry of names drawn from Roman mythology, Rome's seven hills, and (controversially) the seven deadly sins.

Server names included:
- **The Pantheon**: Minerva, Mercury, Morpheus, Mars
- **The Seven Hills**: Capitoline, Aventine
- **Two-faced Gateway**: Janus (the mail server)
- **The Routers**: Named after the seven deadly sins
